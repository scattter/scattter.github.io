Coding配置与使用入门 ​

该教程只适用于 Mac 电脑, 仅做简单的引导使用.

注意: 需要自备 VPN 才能正常访问GPT.

1.安装本地环境 ​

打开电脑, 使用 option + 空格, 唤起电脑上的搜索框, 输入"终端", 打开该软件, 在软件上分别输入下面命令(一条一条命令的输入, 中间需要等待上一条命令执行完)

bash
# 下载并安装 nvm：
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

# 代替重启 shell
\. "$HOME/.nvm/nvm.sh"

# 下载并安装 Node.js：
nvm install 24

# 验证 Node.js 版本：
node -v # Should print "v24.15.0".

# 验证 npm 版本：
npm -v # Should print "11.12.1".

2. 下载 Codex 客户端 ​

目前主流的大模型客户端有: Claude/Codex/Opencode, 其中只有 Codex 是有图形化界面的, 便于新手操作(当然对老手也便捷😜), 同时 Codex 更新速度很快, GPT 也便于订阅, 所以以这个为教程.

该客户端是Chat gpt 开发的专门用于编程的客户端, 不过除了编程, 也可以用于咨询其他问题, 现在更新后还能直接操作你的 Mac 电脑, 一条龙服务.

// 浏览器打开改链接, 正常安装即可
https://openai.com/codex/

2

软件安装完毕后, Codex有两种登录方式, 一种是直接登录GPT的网页, 授权登录; 一种是使用密钥, 这种一般是买了中转站, 或者公司/自己搭建的一些大模型中转时用. 我们大多数还是使用 GPT 的网页进行授权登录即可.

3. Codex 页面介绍 ​

登录 Codex 后的页面如上图所示 (截图是密钥授权, 所以会有灰色菜单), 图上标识代表:

  1. 选择本地的一个文件夹, 形成一个项目(这个名词只是名词, 其实它还是文件夹, 什么都没变), 新建聊条的时候便可以选择这个项目(文件夹)作为对话的上下文地址, 你可以在这个项目下用自然语言(就是正常说的话) 构建自己的应用

  2. a. 这里有一个 "+" 符号, 点击后你可以添加图片等, 还可以设置"计划"模式, 在改模式下你简单提一个小需求, 如"我想要新建一个网页", 不开计划模式的话大模型可能kuku 就开写了, 开了"计划"模式后, 大模型会主动思考你这个需求, 然后问你, 是不是需要兼容手机端也正常显示这种? 这个模式下它会想到一些你遗漏的点, 所以推荐在适当的时候打开(打开会多费一些 token).

    b. 旁边还有一个大模型的权限, 这里建议直接打开 "完全访问权限" 就行, 其他没什么可说的

  3. 这里就是选择大模型了, 一般使用 GPT-4 就行, 思考设为 "高" 即可.

  4. 这里可以切换你对话的项目, 比如项目 A 你是做一个网页, 项目 B 你是做一个 APP, 那么你在项目 A 下面问项目 B 的事情, 那肯定就问不出来, 所以这就是项目的意义, 区分不同的工作空间. 后面两个选项第一个直接选择本地就行, 不用管; 另一个也是强开发相关的, 也可以暂时先不用管, 先把自己想要实现的项目完成就可以.

4. 构建自己的项目 ​

看完上面第 3 部分, 你应该就创建好自己的项目了, 然后你就可以开始你的 Vibe Coding (氛围编程, 其实就是你说话, 他干活...)了.如下所示:

//提示语
我想要搭建一个网站, 该网站可以让我列出来每日 TODO 事件,当我完成一个事件后, 点击后该事件就可以自动归并到已完成; 如果当天事件没有完成, 那么该事件自动顺移到第二天.
1
2

可以看到, 我的提示词是很简单的, 肯定会有很多遗漏的东西, 但是在上面我打开了计划模式, 这样大模型就会自动帮我去考虑其他场景, 逐步完善这个方案.

大模型如果实现完毕后, 一般会告诉你如何打开这个项目看效果; 如果他没有告诉你, 那么你就可以直接在对话框中问它: 我怎么看到效果? 这就是氛围编程, 你只管指挥就行.

需要注意, 当你在一个聊天内发起一个对话后, 聊天框会多出来一个背景信息窗口的小图标, 鼠标放上去可以看到当前窗口使用了多少. 你可以把该窗口当做大模型的脑容量, 你在这个聊天内和它聊的问题次数和复杂度都会累计到窗口占用中, 当占用快满 ( 100% ) 的时候可以简单理解为它快要脑子不清楚, 开始胡说了, 所以这个时候要新开一个聊天窗口, 继续你没有完成的任务.
